# Playlist Exchanger

A cross-platform playlist migration tool that transfers music playlists between
Spotify and YouTube, built to handle large-scale transfers reliably.

## Features
- Migrated 10,000+ tracks across Spotify and YouTube playlists
- OAuth 2.0 authentication with automatic token refresh to keep sessions
  alive during long-running migrations
- API rate-limit handling to improve reliability on large playlist transfers
- Built with Next.js (frontend) and Node.js (backend)

## Tech Stack
Next.js · Node.js · OAuth 2.0 · Spotify API · YouTube Data API
